# 诗泉 Demo 设计

日期：2026-07-26  
状态：已口头确认，待实现

## 目标

做一个轻量前端 demo，演示 [诗泉 API](https://poetry.palemoky.com/) 的两项能力：**随机刷诗** + **全文搜索**。

## 范围

### 做

- Vite + 原生 HTML/CSS/JS 单页
- 首屏阅读区：进入即随机一首；「换一首」再请求
- 搜索区：关键词搜索，结果列表点击后在阅读区展示
- 简繁切换（`lang=zh-Hans` / `zh-Hant`）
- 宣纸墨韵视觉（米黄纸感、墨色字、印章点缀）
- Vite 开发代理，避免本地 CORS

### 不做

- 作者/朝代/体裁复杂筛选
- API 代码示例 / 调试台
- 登录、后端、自建数据库

## 结构

```
顶栏：印章式品牌 + 简繁切换
阅读区：标题 / 朝代·作者 / 诗句 +「换一首」
搜索区：输入框 + 结果列表
页脚：数据来源说明
```

## 数据

| 能力 | 接口 |
|------|------|
| 随机 | `GET /api/poems/random?lang=...` |
| 搜索 | `GET /api/search?q=...&lang=...` |

响应使用 `data` 字段；诗句为 `content` 字符串数组。

## 错误处理

- 请求中：阅读区显示加载态
- 失败：简短中文错误提示，可重试
- 搜索无结果：列表提示「未找到相关诗词」

## 成功标准

- `npm install && npm run dev` 可本地打开
- 随机与搜索均可正常返回并展示
- 桌面与窄屏均可阅读
